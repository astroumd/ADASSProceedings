ADASS timer
===========
(send comments to fstoehr@eso.org)

Background
----------
The ADASS timer is inspired by the timer used for TED talks giving the presenters
a constant feedback on how they are with time. This typically reduces talk-overruns
and removes the need of the session chairs to waive timing notes or to call out
timing information to the presenter.

Set-up
------
The timer is either placed on a laptop which then can be turned to the presenter
in a way letting the session chair still see the text. Alternatively, as TED does,
a screen can be placed on stage next to the monior-screen showing the slides to
the presenter which is connected via HDMI to the laptop which is set up to share
the display.

In the browser, the full-screen mode can be enabled with F11 in Firefox and Chrome.
This can be set with Menu -> Zoom + diagonal arrow (Firefox) or the square (Chrome)
icon.

Monitoring
----------
The timer will count down from the 12min time for contributed talks or 25min for
invited talks. 1min (3min) before the end of the talk the screen turns yellow to
warn the presenter that the end of the talk is coming soon. Once the time is over,
the counter continues into the negative and the screen turns red.

Session chairs can directly see when the time for questions is up at -3min for
contributed talks or -5min for invited talks. The time text will flash red/white
to provide an additional visual cue for the chairs.

Usage
-----
* Clicking on Start will start the timer. This also works without hitting Reset
  before.

* Clicking on Reset will set the time to either 12min for contributed talks or
  25min for invited talks.

* The menu to Reset and Start the timer for the two types of talks can be toggled
  on and off by clicking with the mouse anywhere or by hitting the space bar. This
  is only enabled when the timer is actually running.

* Hitting the Enter key when the menu is visible will start the 12min timer. In other
  words, hitting space bar and then Enter will start the timer for next contributed
  talk without having to use the mouse.
